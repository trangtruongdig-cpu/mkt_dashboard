# Claude example

Mẫu code Python để gọi Claude API từ workspace này.

## Bước 1: Cài đặt

```bash
python3 -m pip install -r requirements.txt
```

## Bước 2: Cấu hình API key

Sao chép file `.env.example` thành `.env` và thay khóa API:

```bash
cp .env.example .env
```

## Bước 3: Chạy

```bash
python3 claude_example.py
```
